# memo-context — 保存上下文快照

将当前对话中的关键上下文信息（设计意图、已否决方案、已知坑位、当前断点、方向约束）提取为独立快照文件，追加索引到 `.memo/_index.md`。

## 触发条件

- 用户直接输入 `memo-context`
- 主技能 `memo -c` 分发调用

## 快照设计哲学

快照的目的是防止下次会话 AI 产生认知偏差和幻觉。docs 目录已覆盖"项目长什么样"，快照只存 docs 和代码无法回答的信息。

判断标准：**少了这条信息，AI 会不会做出错误决策？** 不会 → 不存。

## 快照 5 维度

| 维度 | 内容 | 防什么 | 提取原则 |
|------|------|--------|----------|
| **设计意图** | 为什么选这个方案而非其他，决策背后的原因 | 防止 AI 看到代码"写得怪"就重构 | 从对话中明确讨论过的设计选择中提取，必须附带原因 |
| **已否决方案** | 用户明确说"不要"的方案或技术方向 | 防止 AI 重复提议已被拒的东西 | 从对话中用户明确否定的提议中提取，一次否决永久有效 |
| **已知坑位** | 遇到的问题 + 怎么解决的 + 还没验证的 | 防止 AI 用同样的方式再踩一次 | 从对话中真实遇到的错误/阻塞中提取，必须包含解法 |
| **当前断点** | 做到哪了、哪些没验证、停在哪了 | 防止 AI 不清楚从哪接手 | 从对话末尾的状态中提取 |
| **方向约束** | 未成文的边界 | 防止 AI 提议违背既定方向 | 从对话中隐含的边界约定中提取，不为凑数编造 |

## 执行流程

### 第一步：从对话提取 5 维度

从当前对话中提取 5 维度的信息，严格遵守提取原则。

每维度输出一个条目列表（支持 0 条维度）。

如果全部 5 维度均为空，输出以下提示并结束流程：
```
ℹ️ 当前对话无可保存的上下文信息
```

### 第二步：推断项目层级和类别

根据当前对话内容，推断本次快照的元信息，用于后续索引条目。

**项目层级（单选）：**

| 层级 | 含义 |
|------|------|
| 全栈 | 前端+后端都改动 |
| 前端 | 仅客户端代码 |
| 后端 | 仅服务端代码 |
| 数据库 | 数据模型、迁移链 |
| 共享 | 前后端共用代码 |
| 工程化 | 构建、脚本、项目配置 |
| 部署 | Docker、CI/CD、打包 |

**类别（可多选，用 `+` 连接）：**

| 类别 | 含义 |
|------|------|
| 新功能 | 新增模块/页面/接口 |
| 修改 | 改变已有业务逻辑（非 bug） |
| 修复 | 修 bug |
| 重构 | 结构优化，功能不变 |
| 优化 | 性能优化、体积缩减 |
| 配置 | 环境、依赖、构建设置 |
| 讨论 | 方案探讨，无代码产出 |
| 决策 | 做出技术或业务定论 |
| 规范 | 编码约定、架构原则 |

### 第三步：写入快照文件

1. 必须通过系统命令获取当前日期时间（例如 `Get-Date -Format "yyyy-MM-dd_HH-mm"`），**禁止凭上下文信息推测或编造**。生成文件名：`YYYY-MM-DD_HH-MM.md`
2. 如果已存在同名文件，追加序号：`YYYY-MM-DD_HH-MM_2.md`
3. 写入 `.memo/` 目录

快照文件格式：

```markdown
# 上下文快照 — YYYY-MM-DD HH:MM

### 设计意图
- [意图1]：原因
- [意图2]：原因

### 已否决方案
- [方案1]：被拒原因

### 已知坑位
- [坑位1]：描述 + 解法

### 当前断点
- [已完成的内容]
- [未验证/未完成的内容]

### 方向约束
- [约束1]
```

### 第四步：追加索引

读取 `.memo/_index.md`，追加一条新条目（status=active）：

_index.md 格式：

```markdown
# 时间戳索引

| 文件名 | 项目层级 | 类别 | 描述 | 状态 |
|--------|----------|------|------|------|
| YYYY-MM-DD_HH-MM.md | [层级] | [类别] | [描述] | active |
```

**描述**：一句话概括本轮上下文的核心变化，不超过 30 字。

### 第五步：输出摘要

```
✅ 快照已保存到 .memo/YYYY-MM-DD_HH-MM.md

变更摘要：
- 项目层级：[层级]
- 类别：[类别]
- 设计意图：X 条
- 已否决方案：X 条
- 已知坑位：X 条
- 当前断点：[简述]
- 方向约束：X 条
```

## 注意事项

- **不做合并**：每一条快照都是独立的上下文信息，不读取旧快照
- 快照文件物理保留不删除，索引的压缩整理由 memo-index 负责

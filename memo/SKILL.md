# memo — 主调度器

memo 是项目上下文管理技能体系的统一入口。通过参数分发到对应的子技能。

## 技能体系

五个技能为同级目录，拷贝到任意 AI 编程终端的 skills 目录下即可使用。

| 技能 | 目录 | 职责 |
|------|------|------|
| **memo-context** | `memo-context/` | 保存快照到 .memo/ |
| **memo-docsync** | `memo-docsync/` | 同步 docs 文档和 MEMO.md 索引 |
| **memo-review** | `memo-review/` | 审查压缩快照 + AI 分析建议 |
| **memo-memory** | `memo-memory/` | 加载快照和 MEMO.md 到上下文 |

> 所有路径引用均基于"五个技能目录互为兄弟目录"的约定。当前技能文件所在目录为 `memo/`，兄弟目录通过 `../<skill-name>/` 访问。

## 触发条件

用户输入 `memo` 或 `memo -[参数]` 时执行。

## 参数映射

| 参数 | 映射技能 | 行为 |
|------|----------|------|
| `-c` | memo-context | 保存上下文快照 |
| `-d` | memo-docsync | 同步 docs 文档 |
| `-r` | memo-review | 审查压缩快照 + AI 分析建议 |
| `-m` | memo-memory | 加载上下文 |

支持空格分隔组合，如 `memo -c -d`。

## 执行规则

**当用户输入了参数时：**

1. 收集所有参数中的标志（如 `-c`、`-d`、`-r`、`-m`）
2. 去重：重复参数只执行一次
3. 按固定顺序排列：`c → d → r → m`（无论用户输入顺序如何）
4. 忽略非法参数并输出警告：
   ```
   ⚠️ 未知参数：-x，已忽略
   只支持 -c、-d、-r、-m
   ```
5. 按排列后的顺序依次加载对应的子技能

**执行顺序约定：** `-c → -d → -r → -m`

示例：
- `memo -c` → 加载 memo-context 技能
- `memo -d` → 加载 memo-docsync 技能
- `memo -r` → 加载 memo-review 技能
- `memo -c -d` → 先加载 memo-context，完成后加载 memo-docsync
- `memo -d -c` → 同样先 c 后 d（按固定顺序，不按输入顺序）
- `memo -c -d -r -m` → 顺序执行全部四个技能

## 无参数时

当用户只输入 `memo` 不带任何参数时，先初始化目录结构，再输出教程。

### 第一步：初始化

检查以下路径，缺失则创建：

- `.memo/` 目录 → 创建（如果不存在）
- `.memo/_index.md` → 创建基础索引模板（如果不存在）：
  ```markdown
  # 时间戳索引

  | 文件名 | 项目层级 | 类别 | 描述 | 状态 |
  |--------|----------|------|------|------|
  ```
- `MEMO.md` → 创建基础模板（如果不存在）：
  ```markdown
  # MEMO

  ## 用户规则

  <!-- 用户可在此区域写入自定义规则、偏好 -->

  ---

  ## 文档索引表

  | 编号 | 文件名 | 相对路径 | 简介 | 状态 | 最后同步 |
  |------|--------|----------|------|------|----------|
  ```
- `docs/` 目录 → 创建（如果不存在）
- `.memo/collate/` 目录 → 创建（如果不存在），从兄弟目录 `memo-review/scripts/` 下找到 `server.py`，拷贝到 `.memo/collate/server.py`（源文件路径：当前 SKILL.md 所在目录的 `../memo-review/scripts/server.py`）

检查 `.gitignore`，如果未包含 `.memo/` 则追加一行。追加前确保文件末尾有换行符（如末尾无换行则先补换行再追加）。

### 第二步：输出教程

```
📋 memo — 项目上下文管理技能体系

▸ 用法
   memo             初始化目录 + 输出教程
   memo -c          保存上下文快照
   memo -d          同步 docs 文档
   memo -r          审查压缩快照 + AI 分析建议
   memo -m          加载上下文
   支持组合：memo -c -d -r（顺序固定 c→d→r→m）

▸ 技能说明

   1. memo-context（memo -c）
      从对话提取 5 维度信息，保存为 .memo/ 目录下的时间戳快照文件，并追加索引。
      保存时机：完成一个功能、做出重要决策、发现坑位、准备结束对话。

   2. memo-docsync（memo -d）
      分析当前对话中的文档变更，推荐需要同步的 docs 文档，
      经用户确认后更新 docs 文件及 MEMO.md 中的文档索引表。
      只同步已确认的事实，不将讨论中的假设写入文档。

   3. memo-review（memo -r）
      读取 active 快照交叉对比去重，结合项目状态（docs/ + MEMO.md）生成 AI 建议，
      在审查页面中逐条确认删除/保留/提全局后，写入新快照并更新索引。
      MEMO.md 中的全局条目也会一并展示，供用户决定保留或删除。

   4. memo-memory（memo -m）
      加载 .memo/ 下所有 active 快照和 MEMO.md 到当前上下文，
      让 AI 了解项目设计意图、历史决策、已知坑位和当前状态。
      在开始新会话或接手项目时使用。

▸ 推荐工作流
   开始工作 → memo -m（加载项目上下文）
   完成阶段 → memo -c（保存上下文快照）
   改动文档 → memo -c -d（保存快照 + 同步文档）
   定期维护 → memo -r（审查压缩快照 + AI 分析建议）
   首次使用 → memo（初始化目录结构）
```
